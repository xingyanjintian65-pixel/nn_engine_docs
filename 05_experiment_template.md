## 7. わかった制約・課題

| No  | 内容                                                                                                    | 影響                                              |
| --- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------- |

| 3   | 認可のリダイレクト先がコンテナ内の `127.0.0.1` のランダムなポートになる。`compose.yml` が公開しているのは 5000 番だけなので、ホストのブラウザから届かない        | `token.json` がない PC では、初回の認可で止まる                |
| 4   | パスが `/workdir/...` の絶対パスと `.docs/...` の相対パスで混在している                                                    | コンテナの外や別のフォルダから実行すると、ファイルが見つからない                |

| 6   | 初回の実行は `no such data` のエラーで終わる                                                                        | 新しい PC では2回実行しないと連携まで進まない                       |
| 7   | カレンダーと Drive でスコープが別のため、認可が2回必要になる                                                                    | 初回の手間が2倍になる。2つのスコープをまとめて要求すれば1回で済む              |

| 表示                                     | 原因                                    |

## 9. 次の機能追加への提言

- 推奨する次の機能：どの PC でも初回の認可が通るようにする（§7 の No.2〜4、6）。そのうえで、Drive へのバックアップを本実装にする
- 理由：連携の処理そのものはできているが、PC が変わると動かないため、ほかの機能を足しても使えない。Drive へのバックアップは処理がほぼ完成していて、PC を移るときにも役立つ
- 見送るもの・理由：カレンダーへの登録の本実装。重複を防ぐ仕組みがないと、実行のたびに予定が増える

**初回の認可を通すための案**

| 案                                              | 内容                                                         | 注意点                                    |
| ---------------------------------------------- | ---------------------------------------------------------- | -------------------------------------- |
| コードを貼り付ける方式に変える（yup-oauth2 の `Interactive`）     | 表示された URL をブラウザで開き、リダイレクト後の URL に含まれるコードを端末に貼り付ける          | コンテナの中でも確実に動く。貼り付けの手間がある               |
| 動く PC の `token.json` をコピーする                    | `setting.json` と同じ経路でコピーする                                 | コードの変更はいらない。同意画面が「テスト」だと7日で切れ、同じ問題に戻る |
| ポートを固定して公開する（`HTTPPortRedirect`）              | ポートを決めて `compose.yml` で公開する                               | 待ち受けが `127.0.0.1` に限られるため、これだけでは届かない    |

あわせて、`setting.json` がないときは「`.docs/setting.json` を置く」と案内して終了コードを 1 にすると、どの PC で何が足りないかがすぐわかる。
